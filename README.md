# Аннотация

Настоящий документ является руководством пользователя по эксплуатации информационной системы **«Музыкальная школа»**. Данное руководство содержит информацию о назначении системы, установке и основных операциях.

Настоящий документ разработан в соответствии с ГОСТ 34 РД 50-34.698-90 «Автоматизированные системы. Требования к содержанию документов» и ГОСТ 19 «Единая система программной документации (ЕСПД)».

---

# Введение

Информационная система «Музыкальная школа» представляет собой клиент-серверное приложение для автоматизации учета успеваемости. 

Основные возможности программы:
- Авторизация и регистрация пользователей с разграничением прав доступа.
- Учет текущей успеваемости и результатов экзаменов.
- Быстрый поиск ученика по фамилии.
- Формирование аналитических отчетов.

---

# Назначение и условия применения

Система предназначена для использования в учебных заведениях дополнительного образования (музыкальных школах). 

Условия применения:
- Операционная система: Windows 10/11 или Linux.
- Веб-браузер: Google Chrome, Яндекс.Браузер, Mozilla Firefox.
- Наличие локальной сети или доступа в Интернет.

# Описание операций

**Выставление текущей оценки:**
1. Перейдите в раздел «Успеваемость и экзамены».
2. Выберите ученика из выпадающего списка.
3. Введите числовое значение от 2 до 5.
4. Нажмите кнопку «Сохранить».

*Пример SQL-запроса для формирования списка отличников (с отступами):*
```sql
    SELECT student_name, class_num 
    FROM Students 
    WHERE student_id IN (
        SELECT student_id 
        FROM Grades 
        GROUP BY student_id 
        HAVING MIN(grade_value) = 5
    );
```
